# Release candidate 1.0.0-rc.1
## Install
Python 3.10+. Create a virtual environment, activate it, then `python -m pip install -r requirements.txt`. Run `python -m unittest discover -s tests -v` and `python dashboard.py`. Keep the repository intact. For Codex, explicitly provide the repository path and run `python install_skills.py /path/to/project/.agents/skills` if that is your configured skills directory. Installer refuses existing skill folders; review and migrate them manually. Skill discovery and execution in a live Codex session have not been tested.
## Data and security
SQLite stores local project and evidence records without encryption. Back up the database with the server stopped. Do not store secrets or personal customer data in evidence. Local server binds to loopback and checks Host and a random write token; it is not designed for shared or public hosting. Provider credentials are environment-only. Imported content is untrusted. Schema enforcement covers project and evidence records at workspace boundaries, not all method-specific payloads or legacy CLI commands.
## Release gate
Offline unit tests and local HTTP smoke tests must pass. Before production: validate provider credentials and response contracts with explicit budget approval; implement crawler with robots policy and SSRF defenses; test browser UI and accessibility; audit dependencies and security; implement authentication if hosting; verify real Codex skill activation; add method-specific schemas, automated execution and scheduled monitoring. No deployment is authorized by this release. No live SEO data or live model tests were used.
