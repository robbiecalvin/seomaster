# Section 10
Read-only adapters for Search Console, GA4 and PageSpeed Insights. Supply GOOGLE_ACCESS_TOKEN (short-lived OAuth access token with appropriate read scope) or PAGESPEED_API_KEY via environment. No OAuth enrollment or refresh is implemented. Explicitly instantiate ProviderClient(authorized=True) only after approving the request and possible costs. Fixed provider hosts, no redirects, 20-second timeout, 5 MB response cap, per-client pacing, no automatic retries. Raw responses need normalization and evidence review. Never log request URLs or tokens. DataForSEO, Ahrefs, Semrush and Bing exports can be imported as evidence; native adapters and live crawling remain pending. Do not use private URLs with PageSpeed. No live requests tested.
